# Astro Health — متابعة صحة رواد الفضاء

[![CI](https://github.com/LOKA-HQ/astro-health/actions/workflows/ci.yml/badge.svg)](https://github.com/LOKA-HQ/astro-health/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

[English](README.md) · **العربية**

برنامج لمتابعة صحة رواد الفضاء في المهمات الطويلة، من تطوير فريق **NASA 6 of October** لتحدي **NASA Space Apps Challenge 2026** (التحدي 05: *إنشاء برنامج لمتابعة صحة رواد الفضاء*).

يتابع البرنامج العلامات الحيوية ونتائج تحاليل الدم وبيئة الإشعاع، ويصدر تنبيهات مرتبة حسب الخطورة، ويحكم على كل قراءة بحدود تناسب **الشخص** و**المكان** بدل مدى ثابت واحد للجميع في كل مكان.

> نموذج أولي لهاكاثون وليس جهازًا طبيًا.

## أهم الميزات

- **عتبات شخصية.** تُحسب الحدود من تاريخ قياسات كل رائد نفسه. نبض راحة 108 يُعتبر حرجًا لمعظم الناس، لكنه طبيعي تمامًا لمن يتراوح نبضه المعتاد بين 100 و120.
- **الوعي بالمكان.** القراءة نفسها تعني شيئًا مختلفًا على الأرض، وفي مقصورة طائرة، وأثناء الإطلاق، وعلى محطة الفضاء، وفي الطريق إلى المريخ، وعلى سطحه. تتكيف الحدود مع البيئة، ويمكن تحديد البيئة يدويًا أو استنتاجها من القياسات. كل تعديل مبني على مصدر منشور (انظر [docs/SOURCES.md](docs/SOURCES.md)).
- **حواجز أمان.** يمكن للعتبة الشخصية أن تشدّد الحدود بحرية، لكنها لا تخفّفها إلا إذا كان خط الأساس لدى الشخص خارج المدى الطبيعي أصلًا. وهناك حدود مطلقة (مثل SpO2 أقل من 90%) تبقى حرجة دائمًا.
- **بيانات حقيقية حيث وُجدت.** 13,193 قياسًا سريريًا ومناعيًا من مهمة Inspiration4 (NASA OSDR)، وأحداث الطقس الفضائي الحية من NASA DONKI، وتدفق البروتونات من NOAA GOES. أما العلامات الحيوية فاصطناعية وموسومة بذلك في كل استجابة.
- **توقع الاتجاه.** نظرة على الأيام السبعة القادمة تنبّه للمؤشرات المتجهة نحو حد التحذير.

## لوحة التحكم

- **Overview:** التنبيهات الحرجة وآخر العلامات الحيوية واتجاهات 14 يومًا ولقطة الإشعاع وجاهزية الطاقم.
- **Body:** نموذج ثلاثي الأبعاد للرائد (Three.js) ينبض بحسب معدل نبض الراحة، مع 8 مؤشرات حيوية ورسوم 30 يومًا.
- **Labs:** نتائج Inspiration4 السريرية والمناعية مقارنةً بالمدى المرجعي وبخط الأساس الشخصي، مع فلاتر وتقرير أسبوعي.
- **Environment:** تدفق بروتونات GOES-18 ومقياس NOAA S وأحداث DONKI وجرعات مرجعية، مع تحديث عند الطلب.
- **Alerts:** تدفق تنبيهات واحد يجمع التحاليل والعلامات الحيوية والإشعاع (48 تنبيهًا بالإعدادات الافتراضية).

خيارات العتبات الشخصية والبيئة والتوقع متاحة عبر الـ API فقط حاليًا، ولوحة التحكم لا تعرضها بعد.

## التشغيل السريع

باستخدام Docker:

```bash
docker compose up --build
```

- لوحة التحكم: http://localhost:8080
- الـ API: http://localhost:8000 (والتوثيق التفاعلي على `/docs`)

بدون Docker:

```bash
# الخادم (Terminal 1)
cd backend
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py

# الواجهة (Terminal 2)
cd frontend
npm install
cp .env.example .env
npm run dev          # http://localhost:5173
```

الاختبارات:

```bash
cd backend
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest -q
.venv/bin/ruff check .
```

يعمل فحص الجودة نفسه مع بناء الواجهة تلقائيًا في GitHub Actions مع كل push وpull request.

## العتبات الشخصية والواعية بالمكان

تقبل هذه المسارات المعاملات نفسها: `/alerts` و`/crew/{id}/alerts` و`/crew/{id}/thresholds` و`/crew/{id}/assessment` و`/crew/{id}/forecast`. بدون أي معامل يبقى السلوك الأصلي بعتبات ثابتة.

| المعامل | القيم | المعنى |
|---|---|---|
| `profile` | `generic` (افتراضي)، `personal` | حدود ثابتة للجميع، أو حدود تُتعلَّم من تاريخ الرائد نفسه |
| `environment` | `earth_ground` (افتراضي)، `atmosphere`، `launch`، `iss`، `mars_transit`، `mars_surface` | مكان الرائد الآن |
| `baseline_environment` | نفس القيم، الافتراضي `earth_ground` | المكان الذي سُجّل فيه خط الأساس. استخدم قيمة `environment` نفسها بعد إعادة تعلّم خط الأساس في المكان |
| `days_in_environment` | رقم، اختياري | عدد الأيام في البيئة الحالية، ليتدرّج التكيّف البطيء (حرارة الجسم في انعدام الوزن). إن حُذف لا يُطبَّق هذا التعديل |

**كيف تُبنى العتبة الشخصية:**

1. **خط الأساس:** وسيط قياسات الرائد وتشتت مقاوم للقيم الشاذة (1.4826 × الانحراف المطلق الوسيطي). تُستثنى آخر 7 أيام كي لا تُتعلَّم المشكلة الجديدة على أنها "طبيعية".
2. **الحدود:** التحذير عند خط الأساس ± 2.5 تشتت (حد Leys وزملائه 2013)، والحرج عند ± 3.5 (حد Iglewicz وHoaglin).
3. **البيئة:** تتحرك القيمة المتوقعة بحسب تعديل البيئة.
4. **حواجز الأمان:** العتبة الشخصية تشدّد فقط، إلا إذا كان خط الأساس نفسه خارج المدى الطبيعي (وعندها تُنبّه الاستجابة وتوصي بمراجعة طبية). النوم والمزاج والتوتر لا تُخفَّف حدودها أبدًا، فمن ينام 6 ساعات باستمرار لديه نقص يجب إظهاره وليس "طبيعيًا شخصيًا". الحدود المطلقة حرجة دائمًا، ومع أقل من 7 أيام من البيانات تُستخدم العتبات العامة.

**ماذا تغيّر كل بيئة** (تُطبَّق فقط التعديلات التي تدعمها قياسات منشورة، وحيث لا دليل أو الدليل متضارب يكون التعديل صفرًا):

| البيئة | التغيير | الأساس |
|---|---|---|
| `atmosphere` | حدود SpO2 أقل بـ 3 نقاط | تشبّع الأكسجين الشرياني 96% عند مستوى البحر مقابل 93% عند 7,500 قدم، وحد المقصورة 8,000 قدم (National Research Council 2002) |
| `launch` | حدود النبض +30، وسقف 160 | نبض قادة أبولو بلغ نحو 120 عند الهبوط، وبلغ 160 عند طاقم المكوك بعد الهبوط |
| `iss` و`mars_transit` | حرارة الجسم +1.0 °م تدريجيًا خلال 75 يومًا، والضغط الانقباضي −7 | 11 رائدًا على المحطة: +1.01 °م مع استقرار قرب اليوم 75 (Stahn 2017)، والضغط أقل بـ 7–10 ملم زئبق (Norsk 2015 وHughson 2017) |
| `iss` و`mars_transit` | النبض والنوم لا يتغيران | النبض لم يتغير، والنوم على المحطة نحو 6 ساعات مقابل 8.5 مجدولة، وهو نقص يجب أن يبقى ظاهرًا (Barger 2014) |
| `mars_surface` | لا تغيير | تأثير جاذبية 0.38 g على العلامات الحيوية للإنسان غير معروف |

يعرض `GET /api/v1/environments` كل تعديل مع دليله، ويستنتج `GET /api/v1/environments/detect?body=earth&altitude_km=408&accel_g=1` البيئة من القياسات. التفاصيل الكاملة والمراجع والفجوات المعروفة في [docs/SOURCES.md](docs/SOURCES.md).

## القيود

- **بيانات التحاليل ليست من مهمة إلى المريخ.** Inspiration4 رحلة مدنية مدتها ثلاثة أيام في مدار أرضي منخفض بأربعة أفراد.
- **العلامات الحيوية اصطناعية**، فتنبيهاتها وتوقعاتها تُظهر عمل المنظومة وليس فسيولوجيا حقيقية. استخدم الحقل `data_source` للتمييز.
- **تعديلات البيئات مبنية على دراسات صغيرة** (8–11 رائدًا وخمسة قادة أبولو) ولم تُراجَع سريريًا. لم نجد مصدرًا للعلامات الحيوية عند 0.38 g ولا لسلسلة نبض عند الإطلاق من الأرض، وهي فجوات موثّقة. تحتاج القيم مراجعة طبيب رحلات فضائية قبل أي استخدام حقيقي.
- **البيئة معامل يُمرَّر** أو تُستنتج من قياسات بسيطة، وليست مربوطة بجدول مهمة حقيقي بعد، ولوحة التحكم لا تستخدمها.
- **التوقع تقدير بسيط:** اتجاه خطي مقاوم لآخر 14 يومًا دون نموذج شخصي أو تحقق سريري.
- **لا توجد مصادقة.** البيانات الصحية الحقيقية تحتاج تحكمًا بالوصول وتدقيقًا ومراجعة خصوصية قبل أي نشر.
